# Takeaway ePOS System

A desktop point-of-sale (ePOS) system developed using C# and SQL Server for managing takeaway orders and customer transactions.

## Overview

This project is a takeaway ePOS system designed to provide a simple interface for managing orders, menu items and customer transactions.

The application uses a SQL Server database to store and manage the system's data, with C# handling the application's functionality and user interface.

## Technologies Used

* **C#**
* **.NET / Visual Studio**
* **SQL Server**
* **SQL**
* **Git & GitHub**

## Features

* Takeaway order management
* Menu/item management
* Customer and order information
* SQL Server database integration
* Data storage and retrieval
* User-friendly graphical interface
* Order and transaction processing

## Database

The application uses Microsoft SQL Server as its database system.

The database stores information required by the application, allowing the ePOS system to retrieve, add and update data during normal operation.
